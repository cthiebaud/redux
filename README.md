# redux

Musical settings of poems. Deployed at https://redux.cthiebaud.com via
GitHub Pages, serving `main` directly — no build step.

## Pieces

- alerte
- bateau
- brouillard
- c_est_pas_beau_à_voir
- larme
- lézard
- matsubaba
- nous_partirons
- sensation

Each piece is its own directory: score, lyrics, audio, and a standalone
HTML page.
